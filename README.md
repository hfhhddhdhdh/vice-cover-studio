Vice Cover Studio turns your photo and a caption into GTA 6-style multi-panel cover art: quad, hero, split and solo panel layouts, per-panel crop and positioning, Vice City sunset and neon colour grades, bold poster lettering, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080 — fully offline from static files.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
